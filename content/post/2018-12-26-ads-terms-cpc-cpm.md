## 前言

做后台系统或数据报表时经常碰到广告投放侧的术语：CPA、CPS、CPM、CPT、CPC。五个缩写长得像，区别全在「按什么付费」。这篇一次讲清——按付费锚点从「展示」到「成交」排列，正好是一条转化漏斗。

## 一、五种计费模式

**CPM（Cost Per Mille，每千人成本）**：按展示付费，只要展示了广告主的广告内容，每满一千次曝光就计一次费。品牌广告主用得最多——他们买的是「让更多人看到」。

**CPC（Cost Per Click，每点击成本）**：按点击付费，用户点了广告才计费，展示不计。效果广告的经典模式，广告主只为「感兴趣的人」付钱。

**CPA（Cost Per Action，每行动成本）**：按投放的实际效果计费——用户完成了注册、下载、填问卷等指定动作才计费，不限投放量。EDM 邮件营销里很常见。

**CPS（Cost Per Sales，每销售成本）**：按实际成交的产品数量换算广告费。适合购物、导购、导航类站点，需要精准流量才带来转化——对媒体方风险最大、对广告主最划算。

**CPT（Cost Per Time，每时间段成本）**：按时间包段付费，比如「一个星期多少钱」的固定收费。国内很多网站开屏、固定位采用这种模式，简单粗暴。

## 二、沿转化漏斗理解

五个模式对应漏斗的不同层级，风险归属完全不同：

```txt
展示 → 点击 → 行动 → 成交
CPM    CPC    CPA    CPS        （CPT 在体系外：按时间包断）
```

| 模式 | 付费锚点 | 广告主风险 | 媒体方风险 |
| - | - | - | - |
| CPM | 曝光量 | 高（展示≠效果） | 低 |
| CPC | 点击数 | 中 | 中 |
| CPA | 注册/下载等行动 | 低 | 高 |
| CPS | 实际成交 | 最低 | 最高 |
| CPT | 时间段 | 固定 | 固定 |

**越靠近漏斗底部，风险越向媒体方转移，单价也越高**——一个 CPS 的佣金远高于一次 CPC 的点击价。之所以存在多种模式，本质是广告主和媒体方之间风险定价的博弈。

## 三、常见衍生指标

结合这几个术语，看投放报表时还会遇到：

- **eCPM**（effective CPM）：把 CPC/CPA 等收入折算成千次展示收益，媒体方横向比较不同广告变现效率的统一口径
- **CTR**（Click Through Rate）：点击率 = 点击/展示，衔接 CPM 和 CPC 的关键转化率
- **CVR**（Conversion Rate）：转化率 = 行动或成交/点击，衔接 CPC 与 CPA/CPS
- **ROI**（Return On Investment）：投资回报，广告主视角的最终衡量

## 总结

一句话记忆：**CPM 卖曝光、CPC 卖点击、CPA 卖行动、CPS 卖成交、CPT 卖时段**。看到报价时先问「计费锚点在漏斗哪一层」，风险归属和合理单价区间就都清楚了。
